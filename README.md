
# StudyFlow

## Sobre o projeto

O StudyFlow é um sistema de organização escolar desenvolvido para ajudar estudantes a controlar suas atividades, trabalhos, provas e prazos de entrega.

## Objetivo

Facilitar a rotina dos estudantes por meio de uma plataforma simples e organizada.

## Integrantes

- Isabelle
- Rebeka
- Kiara
- Larissa

## Funcionalidades

- Cadastro de atividades
- Organização por matérias
- Controle de prazos
- Marcação de atividades concluídas
- Lembretes de provas
