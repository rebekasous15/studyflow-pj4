# MANUAL DE OPERAÇÃO — STUDYFLOW

## 1. Apresentação do projeto

O StudyFlow é um sistema de organização escolar desenvolvido para ajudar estudantes a organizar suas atividades, trabalhos, provas e prazos de entrega.

## 2. Integrantes

- Isabelle
- Rebeka
- Kyara
- Larissa

## 3. Objetivo

Facilitar a rotina dos estudantes por meio de um sistema simples e organizado, permitindo cadastrar atividades, acompanhar datas de entrega e controlar tarefas concluídas e pendentes.

# ETAPA 1 — COMO TRABALHAMOS

## Como as tarefas chegam até a equipe?

As tarefas chegam por meio das orientações do professor e das necessidades identificadas durante o desenvolvimento do StudyFlow. Primeiro, lemos o que precisa ser feito e conversamos para entender cada atividade.

## Como decidimos quem faz o quê?

As tarefas são divididas entre as quatro integrantes, considerando a facilidade e o conhecimento de cada uma. Todas podem ajudar quando alguma integrante tiver dificuldades.

## Como sabemos que uma tarefa está pronta?

Uma tarefa está pronta quando:

- [ ] O código ou atividade foi desenvolvido corretamente.
- [ ] A funcionalidade está funcionando.
- [ ] Não apresenta erros durante os testes.
- [ ] A equipe revisou o resultado.
- [ ] A documentação foi atualizada.

## O que fazemos quando alguém trava?

Quando alguma integrante encontra dificuldades, explica o problema no grupo e informa o que já tentou fazer. As outras integrantes tentam ajudar. Se ninguém conseguir resolver, pedimos orientação ao professor.

# ETAPA 4 — COMBINADOS DE COMUNICAÇÃO

A equipe utilizará principalmente o WhatsApp para conversar, compartilhar informações e resolver dúvidas relacionadas ao projeto.

| Combinado | Acordo da equipe |
|---|---|
| Tempo de resposta esperado | Até 24 horas. |
| Horário em que ninguém precisa responder | Depois das 21h. |
| Qual canal para cada assunto | WhatsApp para conversas e GitHub para códigos e documentação. |
| O que conta como urgente | Problemas que impedem o andamento do projeto ou comprometem o prazo de entrega. |

## Modelo de pedido de ajuda

Quando alguma integrante precisar de ajuda, deverá informar:

1. O que eu quero fazer.
2. O que está acontecendo.
3. Onde (arquivo, tela ou rota).
4. O que eu já tentei.
5. O que eu preciso de você.

## Modelo de daily por texto

**ONTEM:** O que consegui realizar no projeto.

**HOJE:** O que pretendo desenvolver ou concluir.

**TRAVADO:** Dificuldades encontradas que precisam de ajuda.
