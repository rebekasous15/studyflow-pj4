PROJETO 4 — MANUAL DE OPERAÇÃO DA EQUIPE

StudyFlow - Sistema de Organização de Atividades Escolares

Integrantes: Isabelle, Rebeka, Kiara e Larissa.

Objetivo do projeto: Desenvolver um sistema que ajude estudantes a organizar atividades, trabalhos, provas e prazos escolares, evitando esquecimentos e atrasos.

ETAPA 1 — COMO TRABALHAMOS
1. Como as tarefas chegam até a equipe?

As tarefas chegam por meio das orientações do professor e das necessidades identificadas durante o desenvolvimento do StudyFlow. Primeiro, lemos o que precisa ser feito e conversamos para entender cada atividade.

2. Como decidimos quem faz o quê?

As tarefas são divididas entre as quatro integrantes, considerando a facilidade e o conhecimento de cada uma. Todas podem ajudar quando alguma integrante tiver dificuldades.

3. Como sabemos que uma tarefa está pronta?

Uma tarefa está pronta quando:
- [ ] O código ou atividade foi desenvolvido corretamente.
- [ ] A funcionalidade está funcionando.
- [ ] Não apresenta erros durante os testes.
- [ ] A equipe revisou o resultado.
- [ ] A documentação foi atualizada.
4. O que fazemos quando alguém trava?

Quando alguma integrante encontra dificuldades, explica o problema no grupo e informa o que já tentou fazer. As outras integrantes tentam ajudar. Se ninguém conseguir resolver, pedimos orientação ao professor.
