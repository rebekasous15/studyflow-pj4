# ADR 001 — Escolha do StudyFlow como sistema de organização escolar

**Data:** 26/11/2026

**Status:** Aceita

## Contexto

A equipe precisava escolher uma ideia de projeto que solucionasse um problema presente na rotina dos estudantes. Percebemos que muitos alunos têm dificuldades para organizar atividades, lembrar das datas de entrega e acompanhar provas.

## Decisão

Decidimos desenvolver o StudyFlow, um sistema de organização escolar que permite cadastrar atividades, separar tarefas por matérias e acompanhar prazos.

## Consequências

**Pontos positivos:**
- O sistema poderá facilitar a organização dos estudantes.
- A ideia é simples e atende a uma necessidade real.
- As funcionalidades podem ser desenvolvidas por etapas.

**Pontos negativos:**
- Será necessário tempo para desenvolver e testar todas as funcionalidades.
- Algumas funções poderão exigir conhecimentos técnicos que a equipe ainda precisa desenvolver.
- O sistema precisará de atualizações para continuar atendendo às necessidades dos estudantes.
